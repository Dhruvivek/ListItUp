# Work

## Overview

The **Work** section is the main workspace in application where users manage their day-to-day work. It acts as the central hub for accessing personal tasks, projects, portfolios, and other work-related features. From here, users can organize their work, collaborate with teammates, and navigate to different sections of the workspace.

## Contains
    -Home
    -Inbox
    -My Tasks
    -Projects
    -Portfolios
    -Work
    -Starred

# Home

## Overview

The **Home** page is the default page that users see after opening the **Work** space. It gives a quick overview of ongoing work by showing tasks, projects, collaborators, and other useful widgets. Users can also customize the page by adding or removing widgets based on their needs.

## Header

The top section of the Home page contains basic information and quick dashboard controls.

### Contains

- **Current Date** – Displays the current day and date.
- **Greeting** – Shows a greeting based on the current time (e.g., Good Morning, Good Afternoon).
- **Time Filter** – Allows users to switch between **My Week** and **My Month**.
- **Tasks Completed** – Displays the number of tasks completed in the selected time period.
- **Collaborators** – Shows the number of collaborators for the selected period.
- **Customize** – Opens the customization panel where users can manage dashboard widgets.

---

## Widgets

The Home page is made up of different widgets. Each widget provides quick access to a specific area of work. 

### Learn App

Shows learning resources, tips, and guides to help users understand and use Asana.

### My Tasks

Displays tasks assigned to the current user. Tasks are grouped into **Upcoming**, **Overdue**, and **Completed** sections. Users can also create new tasks directly from this widget.

### Projects

Shows recently accessed projects and provides an option to create a new project or open an existing one.

### Tasks I've Assigned

Displays all tasks that have been assigned by the current user to other collaborators. This helps users keep track of delegated work.

### People

Shows collaborators available in the workspace for quick access.

### Custom Widgets

Users can personalize the Home page by adding widgets such as **Portfolios**, **Status Updates**, and other supported widgets.

---

# Inbox


## Overview

The **Inbox** page is the notification center of the Work space. It displays updates, task activities, mentions, and other notifications related to the user's work. 

## Header

The Inbox header contains the following options:

- **Activity** – Displays all recent notifications and updates.
- **Bookmarks** – Displays notifications that have been bookmarked by the user.
- **Archive** – Displays notifications that have been archived.
- **@Mentioned** – Displays notifications where the user has been mentioned.
- **Add Tab (+)** – Allows users to create additional custom tabs to organize notifications.
- **Manage Notifications** – Opens the notification settings page where users can configure notification preferences.

> **Note:** Exept manage notifications and add tab provides options such as **Rename**, **Set as Default**, **Make a Copy**, and **Remove**.

---

## Activity

The **Activity** tab displays all recent notifications, updates, task activities, and messages from projects and collaborators.

### Features

- Displays notifications.
- Supports filtering notifications.
- Allows sorting notifications (e.g., Newest,relevance).
- Supports different density views (Detailed, Compact, etc.).
- Each notification can be bookmarked or archived and having option mark as read.


If a notification is bookmarked, it is automatically added to the **Bookmarks** tab.

If a notification is archived, it is removed from the **Activity** tab and moved to the **Archive** tab.

---

## Bookmarks

The **Bookmarks** tab contains all notifications that have been bookmarked by the user for quick access.

### Features

- Displays only bookmarked notifications.
- Bookmarked notifications remain available until they are removed from bookmarks.
- Removing a bookmark automatically removes the notification from this tab.

---

## Archive

The **Archive** tab contains notifications that have been archived.

### Features

- Displays archived notifications.
- Archived notifications are hidden from the **Activity** tab.
- Unarchiving a notification removes it from the Archive tab and restores it back to the **Activity** tab.

---

## @Mentioned

The **@Mentioned** tab displays notifications where the current user has been mentioned by another collaborator.

### Features

- Displays only mention-related notifications.

---

## Custom Tabs

Users can create additional tabs using the **Add Tab (+)** button to organize notifications based on their workflow.

### Available Actions

- Rename
- Set as Default
- Make a Copy
- Remove

---

# My Tasks

## Overview

The **My Tasks** page is a personal workspace where users can view, organize, and manage all tasks assigned to them. It provides multiple views to manage tasks based on different workflows, allowing users to switch between list, board, calendar, dashboard, and file views.

## Available Views

The following views are available in the **My Tasks** page:

- **List** – Displays tasks in a structured table format.
- **Board** – Displays tasks as Kanban cards grouped into sections.
- **Calendar** – Displays tasks based on their due dates.
- **Dashboard** – Displays task statistics and progress using charts and widgets.
- **Files** – Displays all files attached to tasks.
- **Add View (+)** – Allows users to create additional custom views.

---

## Common Actions

The following actions are available across most views:

- Add Task
- Share
- Customize View
- Search Tasks
- Filter Tasks
- Sort Tasks
- Group Tasks

---

# List View

The **List** view displays tasks in a table format with customizable columns.

### Features

- Create new tasks.
- Edit task information directly from the table.
- Organize tasks into sections.
- Drag and move tasks between sections.
- Mark tasks as completed.
- Add custom fields.
- Show or hide table columns.

### Columns

- Task Name
- Due Date
- Collaborators

### Section Management

# Portfolio

## Overview

A Portfolio is a collection of related projects. Instead of opening every project individually, users can monitor the progress, health, workload, and timelines of multiple projects from one place.

It is mainly intended for managers, team leads, or anyone who wants a high-level overview of ongoing work.

Example:

```
Workspace
│
├── Portfolio
│   ├── Project A
│   ├── Project B
│   └── Project C
```

A portfolio doesn't contain tasks directly. It only groups projects and summarizes their overall progress.

---

# Portfolio Home

The Portfolio page shows all portfolios available to the user.

Each portfolio card displays:

- Portfolio name
- Number of projects
- Owner
- Recently accessed portfolios

Users can:

- Create a new portfolio
- Open an existing portfolio
- Browse all portfolios

---

# Inside a Portfolio

Clicking a portfolio opens its workspace.

The portfolio contains different views for monitoring the projects inside it.

Available views:

- List
- Timeline
- Dashboard
- Progress
- Workload
- Messages

---

# List View

This is the default view.

It displays all projects in a simple table.

Information shown includes:

- Project name
- Current status
- Progress
- Due date
- Owner

Users can also:

- Add or remove projects
- Search projects
- Filter projects
- Sort projects
- Group projects
- Customize visible columns

---

# Timeline

The Timeline provides a visual schedule of every project in the portfolio.

Unlike the Project Timeline (which displays tasks), the Portfolio Timeline displays entire projects over time. Each project appears as a horizontal bar stretching from its start date to its due date.

This helps users quickly understand:

- Which projects are running simultaneously
- Upcoming project deadlines
- Project duration
- Scheduling conflicts
- Overall roadmap of the portfolio

The timeline supports different zoom levels such as weeks, months, and quarters, along with filtering, grouping, and saved custom views.

---

# Dashboard

The Dashboard provides quick insights into the portfolio using widgets and charts.

Examples include:

- Total tasks
- Completed tasks
- Incomplete tasks
- Overdue tasks
- Project status distribution
- Tasks grouped by project
- Upcoming tasks by assignee

Users can customize the dashboard by adding, removing, or rearranging widgets.

---

It includes:

### Portfolio Status

Overall portfolio health:

- On Track
- At Risk
- Off Track

### Summary

An AI-generated summary of recent activity, project updates, and possible risks.

### Latest Status

Shows the latest status update posted for the portfolio.

### About Portfolio

Displays basic information such as:

- Owner

- Description

### Goals

Displays any goals linked with the portfolio.

### Status History

Shows previous portfolio status updates in chronological order.

### Comments

Team members can discuss portfolio-level updates by commenting and mentioning other members.

---

# Workload

The Workload view helps managers understand how work is distributed across team members.

Each member has their own row, while the timeline shows how many tasks are assigned on each day.

This makes it easier to:

- Spot overloaded members
- Find underutilized members
- Balance work across the team
- Plan future assignments

---

# Messages

Messages provide a common discussion area for everyone in the portfolio.

Unlike task comments, these conversations are related to the portfolio as a whole.

They can be used for:

- Announcements
- Weekly updates
- Discussions
- Decisions
- Sharing important information

---

# Portfolio Status

Each portfolio has an overall status representing its current health.

Available statuses:

- On Track
- At Risk
- Off Track

The portfolio owner can update this status whenever required.

---

Portfolio members can:

- View projects
- View reports

- Comment on updates

Portfolio owners can additionally:

- Edit portfolio details

---

# Relationship

```
Workspace
│
└── Portfolio
      ├── Project
      │      ├── Sections
      │      ├── Tasks
      │      └── Subtasks
      │
      └── Project
```

Projects are where actual work is done.

The Portfolio simply brings multiple projects together and provides a single place to monitor their overall progress.
