# Profile


## Overview

The **Profile** page is the personal workspace of a user. It contains profile information, task overview, collaborators, goals, recently accessed projects. It acts as a quick dashboard for managing personal information and accessing frequently used work items.

---

## Profile Information

The top section displays the user's basic information.

Features:
- Profile picture/avatar
- User name
- Edit profile
- Update profile picture
- Set Out of Office status
- Add team or department
- Add "About Me" information

---

## My Tasks Widget

Displays a quick preview of tasks assigned to the current user.

Features:
- View recent tasks
- Open complete My Tasks page
- Open task details directly
- Shows due dates and project information

---

## Frequent Collaborators

Displays teammates the user collaborates with most often.

Features:
- View frequent collaborators
- Invite teammates
- Open collaborator profile

---

## My Goals

Displays goals created by the user.

Features:
- Create new goals
- Track goal progress
- View goal status
  - On Track
  - At Risk
  - Off Track

---

## My Recent Projects

Displays projects recently opened or worked on.

Features:
- Quick access to recent projects
- Displays project members
- Open project directly
